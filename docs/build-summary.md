# 개발 상태

현재 동작과 실행 절차는 [README](../README.md), 검증 근거는 [verification.md](verification.md)를 기준으로 합니다.

## 이번 수정

- 소유자 서명 API 제거. dApp Kit로 소유자 지갑 연결, OwnerCap 확인, 직접 서명.
- 서버에 소유자 키가 설정돼 있으면 시작 거절. 기존 키스토어의 백업을 확인한 경우에만 .env의 중복 키를 제거하는 마이그레이션 도구.
- Walrus에 기간 중 삭제 불가 저장 요청 후 같은 내용을 읽어 확인. 실패 시 송금 중단.
- 승인 이벤트를 명시적으로 확인. 정책 차단·실행 오류·결과 미확인을 구분.
- 최근 결제의 Walrus 기록을 재사용하는 recall_payments 도구.
- 금액 정밀도 검증, API 입력 검증, 로컬 Host/Origin 제한, 겹치는 결제 요청 차단, 실행 중 요청 ID 재사용 방지.
- Sui Clock에 맞춘 주기형 한도 표시. 기존 계약의 한도 방식은 유지.
- 영구 기록·모든 공격 기록·슬라이딩 24시간 한도처럼 보장하지 않는 표현 수정.

## 유지된 제한

가상 마켓·testnet·단일 사용자 로컬 데모입니다. 공개 서비스용 인증, 온체인 blob 인증, Seal, 자동 보관 연장, 영속 요청 ID, 체인 인덱싱은 미구현입니다. 실제 제공자별 대화·브라우저 지갑 서명 검증은 외부 자격 증명과 지갑 연결이 필요합니다.

## 초기 배포

기존 Sui testnet Package와 Allowance를 계속 사용합니다. 주소와 최초 승인·거절 트랜잭션은 README에 있습니다. 이번 변경으로 새 계약을 발행하거나 자금을 이동하지 않습니다.


## AI 제공자 선택 (2026-09-14)

Claude, Gemini, OpenAI(Codex) 연결과 대시보드 선택 메뉴를 추가했습니다. 세 제공자는 동일한 검증·결제·Walrus 기록 경로를 사용합니다. 키 없는 옵션의 채팅은 비활성화하며 API 장애 뒤 자동 제공자 전환은 하지 않습니다. 제공자와 모델을 판단 기록에 남기고 결제 후 오류에서도 영수증을 보존합니다.

타입 검사·웹 빌드·49개 회귀 테스트와 브라우저 전환 검증이 통과했습니다. Gemini·OpenAI의 실제 대화는 API 키 설정 후 검증해야 합니다. 자세한 범위와 재현 방법은 [검증 기록](verification.md)을 참고하세요.
