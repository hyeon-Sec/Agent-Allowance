## 검증 환경과 한계

사용자 요청에 따라 Anthropic API 키 없이 검증했습니다. 실제 Claude 대화와 도구 선택, 브라우저 지갑 서명, 신규 Sui 송금, 신규 Walrus 업로드는 이번 수정 후 실행하지 않았습니다. 저장·송금 오류 경로는 외부 서비스를 대체한 테스트로 검증했습니다. testnet에서는 기존 상태를 읽기만 했으며, 새 배포나 자금 이동은 하지 않았습니다.

실제 브라우저 지갑이 설치된 사용자 환경에서는 OwnerCap 보유 계정으로 연결한 뒤 정지·재개·한도 변경을 추가 확인해야 합니다. 서버와 같은 사용자 계정의 로컬 Sui 키스토어는 개발 환경에 남아 있습니다. 실제 운영에서는 그 키스토어와 소유자 지갑을 에이전트 환경에서 분리해야 합니다.

## 2026-09-14 실제 Claude 연결 확인

- 로컬 환경의 API 키 설정을 확인했으며 키 값은 출력하지 않았습니다.
- Anthropic Models API 인증과 `claude-opus-5` 접근은 성공했습니다.
- 새 키를 반영해 서버를 시작했고, 브라우저에서 채팅 입력과 전송 버튼이 활성화됐습니다.
- 결제 없는 정책 조회 요청은 Anthropic의 HTTP 400 `invalid_request_error`로 실패했습니다. 제공자가 반환한 원인은 API 크레딧 잔액 부족입니다.
- 실패 시 도구 호출과 결제 결과는 모두 빈 배열이었습니다. 신규 Sui 송금과 Walrus 업로드는 실행하지 않았습니다.
- 잔액 부족을 일반적인 키·연결 오류와 구분해 안내하도록 수정했습니다. 실제 결제·Memory 대화 검증은 크레딧 충전 후 진행해야 합니다.

- 오류 안내 수정 후 TypeScript 검사와 회귀 테스트 23개가 통과했습니다. 서버 재시작 뒤 채팅 활성화·소유자 제어 잠금·브라우저 오류 없음도 다시 확인했습니다. 사용자가 충전 후 알려주기로 했으므로 추가 Claude 요청과 결제 검증은 중단한 상태입니다.

- 세 SDK의 대화 이력 전달, 정책 조회 → 결제 도구 → 최종 응답, 도구 호출 ID 매칭, 추론 서명 보존을 확인했습니다.
- 제공자별 중복 결제 억제, 결과 미확인 후 추가 결제 금지, 결제 후 API 할당량 오류의 영수증 보존과 HTTP 재시도 미실행을 확인했습니다.
- 불완전한 모델 응답에 결제 도구가 포함돼도 실행하지 않습니다. 알 수 없는 도구와 잘못된 결제 입력은 실행 경로에 도달하지 않습니다.
- API가 제공자 값을 검증·전달하고, 같은 요청 ID에서 제공자를 변경한 재요청을 거절하는지 확인했습니다. 공개 설정에는 키 값이 포함되지 않습니다.
- 브라우저 테스트 서버에서 Claude → Gemini → OpenAI 선택 후 각각 요청을 전송했습니다. 실제 요청의 provider 값은 anthropic → gemini → openai였고, 이전 대화 개수는 0 → 2 → 4로 유지됐습니다. 응답마다 선택한 제공자 이름이 표시됐습니다.
- 처리 중 선택 메뉴가 잠기고 완료 후 다시 활성화됐습니다. 390px 모바일 화면의 콘텐츠 너비도 390px로 가로 넘침이 없었습니다. 페이지 오류와 콘솔 오류가 없었습니다.
- 실제 로컬 서버 `http://127.0.0.1:8787`를 재시작했습니다. 세 옵션 표시, Gemini·OpenAI 키 미설정 안내와 채팅 비활성화, 기존 Claude 키 설정의 채팅 활성화를 확인했습니다. 키 존재는 크레딧이나 모델 접근 성공을 뜻하지 않습니다.
- 이번 추가 작업에서는 Gemini·OpenAI 키가 없어 실제 제공자 대화를 실행하지 않았습니다. Anthropic은 사용자의 크레딧 충전 안내를 기다리고 있어 추가 요청을 보내지 않았습니다. 신규 Sui 송금·Walrus 업로드도 실행하지 않았습니다.

```bash

VERIFY_CHAT=1 npm run verify:browser-server
# http://127.0.0.1:8788 에서 각 AI 선택 후 요청 전송
```

이 모드의 답변은 `[테스트 응답]`으로 표시되는 고정 응답이며 외부 서비스를 호출하지 않습니다. `VERIFY_CHAT` 없이 실행하면 모든 모델을 키 미설정으로 표시하는 기존 오류 화면 검증 모드입니다. 테스트 서버는 검증 후 종료했으며 실제 로컬 서버는 실행 중입니다.
